# 键盘快捷键 {#keyboard-shortcuts}

Cutaway 菜单里的所有快捷键。在输入框里输入，可以按它的作用、所在的菜单或按键来找，例如“shift cmd e”。

<Shortcuts />

## 在预览里 {#in-the-preview}

| 要 | 这样做 |
|---|---|
| 选中一个图层 | 点按它 |
| 展开或折叠一个图层的行 | 连按这个图层 |
| 转动图层（3D） | 拖动 |
| 平移 | 滚动；在 2D 下也可以拖动 |
| 以指针为中心缩放 | 双指捏合，或按住 <kbd>⌘</kbd> 滚动 |
| 从所选图层测距 | 按住 <kbd>⌥</kbd> 指向另一个图层 |

## 在图层列表里 {#in-the-layer-list}

| 要 | 这样做 |
|---|---|
| 展开或折叠一行 | 连按它 |
| 展开或折叠一行及其里面的一切 | 按住 <kbd>⌥</kbd> 点按它的展开三角形 |
| 从所选图层测距 | 按住 <kbd>⌥</kbd> 指向另一行 |

## 在属性里 {#in-the-attributes}

| 要 | 这样做 |
|---|---|
| 折叠或展开每一节 | 按住 <kbd>⌥</kbd> 点按一节的标题 |
| 放回 App 会拒绝的值 | <kbd>Esc</kbd>，或离开输入框 |

## 在 App 列表里 {#in-the-app-list}

用方向键选中一个 App，按 <kbd>Return</kbd> 检查它。
