# 预览 {#the-preview}

预览把每个可见的图层画在它在屏幕上的位置，带着它的截图。这一页说明怎样从各个角度查看它。

图层树先到，预览先把图层画成轮廓；每张截图到达后随即出现。进度显示在工具栏里。

## 在 2D 与 3D 之间切换 {#switch-between-2d-and-3d}

在工具栏里选择 **2D** 或 **3D**，或者按 <kbd>⌘1</kbd> 和 <kbd>⌘2</kbd>（**显示 › 2D**、**显示 › 3D**）。

- **2D** 把图层平铺显示，与设备屏幕上一样。
- **3D** 沿深度把它们分开，让你看清谁在谁后面。在图层列表里折叠一行，它的子树就合回一个图层。

每个位置、大小、旋转和缩放都按设备上的样子画出，包括 3D 变换。

## 移动相机 {#move-the-camera}

| 要 | 这样做 |
|---|---|
| 转动图层（3D） | 在预览里拖动 |
| 平移 | 用两指或鼠标滚轮滚动；在 2D 下也可以拖动 |
| 缩放 | 双指捏合，或按住 <kbd>⌘</kbd> 滚动；以指针为中心缩放 |
| 逐级缩放 | **显示 › 放大**（<kbd>⌘=</kbd>）和**显示 › 缩小**（<kbd>⌘-</kbd>） |
| 回到开始的样子 | **显示 › 重置视图**（<kbd>⌘0</kbd>），或预览下方的**重置** |

## 改变层间距 {#change-the-layer-spacing}

在 3D 下，预览下方的滑块设定图层之间的距离，从 0 到 200 点。间距大一些，挤在一起的图层就分开了；设为 0 时图层重新叠在一起，仍保持 3D 视图。

## 显示隐藏的图层 {#show-hidden-layers}

**显示 › 显示隐藏的图层**（<kbd>⇧⌘H</kbd>），或预览下方的眼睛，会把隐藏的或完全透明的图层也画出来，用它们自己的样式，让你找到一个没有显示出来的视图。

## 给图层加轮廓 {#outline-the-layers}

预览下方的边框菜单给图层加上轮廓：

- **关闭**、**单色**（一种颜色）或**按类别**（用列表里图标的颜色）；
- **只显示 App 自己的类**，只给你的类加轮廓；
- **约束的另一端**，标出所选视图的每条约束的另一端（见[约束](/zh-Hans/guide/constraints)）。

**显示 › 边框 › 显示边框**（<kbd>⇧⌘B</kbd>）关闭边框，再按一次恢复上次的样式。

虚拟节点用虚线画轮廓，App 不让出现在图像里的视图画上斜线。<Badge type="info" text="需要 CutawayServer 1.2" />

## 选中一个图层 {#select-a-layer}

- **点按**一个图层选中它；列表和属性随之更新。旁边的标签显示它的名字和大小。
- **指向**一个图层，高亮它和它在列表里的行。
- **连按**一个图层，展开或折叠它的行。

2D 下预览显示 App 合成好的窗口，带模糊、Liquid Glass 和颜色滤镜，不管列表怎样展开。<Badge type="info" text="需要 CutawayServer 1.3" /> 在 3D 下、聚焦时和显示隐藏的图层时，每个图层用它自己的图画出，这些效果可能缺失或与屏幕不同。见[限制](/zh-Hans/integrate/limitations)。

## 刷新 {#refresh}

预览显示的是 Cutaway 请求时 App 的样子。要重新请求：

- **显示 › 刷新**（<kbd>⌘R</kbd>），或工具栏里的**刷新**，重新载入整棵树、每一张截图和所选图层的属性。展开的行、选中的图层和相机都保持不变。
- **显示 › 刷新所选子树**（<kbd>⇧⌘R</kbd>），或某一行的右键菜单里的**刷新子树**，只重新载入这个图层和它的后代，连同它们的截图。

存档不能刷新：它保留的是存储时 App 的样子。

### 自动刷新 <Badge type="info" text="需要 CutawayServer 1.3" /> {#auto-refresh}

打开自动刷新时，App 在图层变化时告诉 Cutaway，Cutaway 自己重新取变化的部分。它默认打开。用边框菜单旁的按钮或**显示 › 自动刷新**关掉；**设置 › 预览**决定新的检查怎样开始。

保存存档时、预览的展开或折叠过渡途中，它会等一等。输入属性值或测距时不会暂停。你打的字留在输入框里，除非选中的图层不在了或它的属性结构变了，这时打的字会丢掉；不想被打扰时，关掉自动刷新。只改了图层画的内容时，App 不一定会报告，所以预览看起来过时时，按 <kbd>⌘R</kbd>。

### 变了什么 {#what-changed}

刷新后，新出现的图层标绿色，变了的标黄色，列表和预览里都有，约一秒半后淡去。折叠的行里有变化时，标出最近的看得见的行。工具栏写出移除了多少个图层。只有图变了、位置和字段没变的图层不标。

在**设置 › 预览**里可以关掉这些标记。
