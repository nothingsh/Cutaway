# 设置 {#settings}

打开 **Cutaway › 设置…**（<kbd>⌘,</kbd>）。修改即时保存；“通用”和“预览”两页有**恢复默认设置**。

## 通用 {#general}

- **语言**：系统默认，或 English、简体中文、繁體中文、日本語、한국어。“系统默认”按“系统设置”里的语言顺序选择。Cutaway 要重新启动才会改变语言：选择**立即重新启动**，或选择**以后**，下次打开时再换。打开着的检查会关闭；重新启动后可以再检查它们的 App。
- **外观**：系统默认、浅色或深色。“系统默认”跟随“系统设置”里的浅色或深色。修改立即应用到所有窗口，不用重新启动。

## 预览 {#preview}

这几项决定**新的**检查以什么样子开始。已经打开的窗口保持原样，重新连接的检查保留它窗口的视图。存档以存储时的视图打开。

- **新的检查打开为**：2D 或 3D。
- **层间距**：3D 下的间距，0 到 200 点。
- **图层**：显示隐藏的图层。
- **边框**：关闭、单色或按类别；**只给 App 自己的类画边框**；**标出全部约束的另一端**。

这些都可以随时在窗口里改；见[预览](/zh-Hans/guide/preview)。

<Shot name="guide-settings-preview" alt="设置的“预览”一页：默认的模式、层间距、隐藏的图层和边框。" />

## 项目 {#projects}

你关联的项目文件夹（**文件 › 关联项目文件夹…**），每个 App 一个：App 的名字、它的 bundle ID 和文件夹。选中一个，可以更换它的文件夹（**更换…**），或把它移除（**移除**）。Cutaway 找不到的文件夹标着**找不到**。

Cutaway 只读取这些文件夹，用来在 Xcode 中打开类、给颜色和文字写出名字。见[源代码](/zh-Hans/guide/source)。
