Cutaway は、実行中の iOS アプリのインターフェースの内部を調べるための macOS アプリです。[CutawayServer](https://github.com/nothingsh/CutawayServer) をアプリに追加し、シミュレータか USB で接続したデバイスで実行すると、Cutaway のリストに表示されます。それを選ぶと、Cutaway はアプリのレイヤーツリー、2D に平面で並べるか 3D で離して配置したすべてのレイヤーのスクリーンショット、そして選択したレイヤーの属性と Auto Layout 制約を表示します。属性に加えた編集は、実行中のアプリに適用されます。

<a id="features"></a>
## 機能

**インターフェースの組み立てを見る**

- すべてのウィンドウのレイヤーツリー。ビューコントローラのルートビューと、各レイヤーやビューを保持しているメンバー変数が示されるので、レイヤーからコードへたどれます。
- すべてのレイヤーのスクリーンショット。2D で平面に、または 3D で離して表示します。マウスやトラックパッドで回転、ズーム、パンし、レイヤーの間隔を変え、非表示のレイヤーを表示できます。
- デバイスの画面上と同じ位置、サイズ、回転、拡大縮小。3D 変換も含みます。
- 計測: ⌥ を押しながら別のレイヤーを指すと、選択中のレイヤーとの距離が 2D でも 3D でも表示されます。

**細部を扱う**

- 選択したレイヤーとビューの属性。用途別の 5 つのセクションに分かれ、枠線の幅と色のように関連する属性は 1 行にまとめられます。編集可能な属性にはコントロールがあります: テキスト、数値、チェックボックス、カラーフィールド、列挙型のポップアップとセグメンテッドコントロール。変更はすぐに実行中のアプリに適用され、⌘Z で取り消せます。
- 選択したビューを参照する Auto Layout 制約。有効でないものが示されます。制約を指すとそのもう一方の端がプレビューで示され、すべての制約のもう一方の端を一度に示すこともできます。もう一方の端をクリックすると、そこへ移動します。
- ツリーの検索、サブツリーへのフォーカス、指定した深さまでの展開、サブツリーだけの更新。

**見つけたものを残す**

- 検査を `.cutaway` アーカイブとして保存し、後でどの Mac でも、デバイスなしで開けます。ツリー、スクリーンショット、属性、制約がすべて、そのときの表示のまま残ります。
- レイヤーのスクリーンショットを、単体またはサブレイヤーを含めて PNG として書き出せます。

**日常の使用のための設計**

- アプリを自動で見つけます。この Mac 上のシミュレータと、USB で接続したデバイスの中からです。
- まずツリーを表示し、スクリーンショットは届き次第表示します。大きなツリーでも応答性を保ちます。
- アプリが戻ってくると再接続します。アプリの状態に追従します: バックグラウンドに移ると Cutaway はそのことを示し、戻ってくると続行します。
- 英語、簡体字中国語、繁体字中国語、日本語、韓国語に対応しています。
- 通信するのはこの Mac 上のアプリと、USB ケーブル越しのアプリだけです。アナリティクスもクラッシュレポートもありません。

<a id="requirements"></a>
## 動作要件

- macOS 14 以降。Metal に対応した GPU を搭載した Mac（macOS 14 が動作するすべての Mac）。
- [CutawayServer](https://github.com/nothingsh/CutawayServer) を組み込んだアプリ。iOS Simulator、または USB で Mac に接続した iPhone か iPad で実行されているもの。

Cutaway はサンドボックス化されていません。USB でデバイスに到達するために使うソケットがサンドボックスの外にあるためです。同じ理由で、Mac App Store の外で配布しています。

<a id="installation"></a>
## インストール

[Releases](https://github.com/nothingsh/Cutaway/releases) ページから `Cutaway-<バージョン>.dmg` をダウンロードして開き、Cutaway をアプリケーションフォルダにドラッグしてください。Cutaway はオープンソースで、そのビルドは Apple の公証を受けていません。そのため初めて開くとき、macOS は開発元を検証できないと表示します。**システム設定 › プライバシーとセキュリティ** を開いて **このまま開く** を選ぶか、次を実行してください。

```sh
xattr -dr com.apple.quarantine /Applications/Cutaway.app
```

**Cutaway › アップデートを確認…** で、新しいリリースが出ているかを確かめられます。Cutaway をソースからビルドすることもできます。[開発](#development)を参照してください。

## クイックスタート

1. iOS アプリに [CutawayServer](https://github.com/nothingsh/CutawayServer) を追加し、起動時に `CutawayServer.start()` を 1 回呼び出します。UIKit と SwiftUI それぞれの 2 行は、サーバーの [README](https://github.com/nothingsh/CutawayServer#readme) にあります。Debug ビルドにのみコンパイルされます。
2. アプリをシミュレータ、またはケーブルで Mac に接続したデバイスで実行します。
3. Cutaway を開きます。数秒以内にアプリがリストに表示されます。それを選んでください。

## Cutaway の使い方

### レイヤーリスト

サイドバーには、すべてのウィンドウのレイヤーがツリーとして並びます。各行には、レイヤーのクラス、そのレイヤーが支えるビュー、それをルートビューとするビューコントローラ、そしてそれを保持しているメンバー変数（`HomeViewController.titleLabel` など）が表示されます。薄く表示された行は、非表示か完全に透明なレイヤーです。アイコンはレイヤーの種類を表し、アプリ独自のクラスは塗りつぶし、システムのクラスは輪郭線で示されます。スクロールしている間、いちばん上の行の祖先はその上に固定されて表示されます。

- 上部のフィールドでツリーを**フィルタ**します。タイトルかクラスにその文字列を含む行が、祖先とともに残ります。
- レイヤーに**フォーカス**する（⌥⌘↓）と、リストでもプレビューでもそのサブツリーだけが表示されます。リストの上のパスから元に戻れます。
- フィルタの隣のメニューから、指定した深さまで、またはすべてを**展開**します（すべてを展開・折りたたむのは ⌥⌘→ と ⌥⌘←）。アプリを初めて検査したとき、ツリーは画面上のビューコントローラまで開かれます。
- 行を**ダブルクリック**すると、展開または折りたたみます。プレビューでレイヤーをダブルクリックしても同じです。

### プレビュー

プレビューは、ツリーが届いたとき、そして各スクリーンショットが届くたびに、表示中のすべてのレイヤーをそのスクリーンショットとともに画面上の位置に描画します。

- **2D または 3D**（⌘1、⌘2）はツールバーで切り替えます。3D ではレイヤーが深さに沿って離して配置されます。リストで行を折りたたむと、そのサブツリーは 1 枚に畳まれます。
- 3D ではドラッグで**回転**、スクロール（2D ではドラッグでも）で**パン**、ピンチまたは ⌘ とスクロールホイールでポインタを中心に**ズーム**します。**表示をリセット**（⌘0）で最初の状態に戻ります。
- 3D での**レイヤー間隔**は、プレビューの下のスライダで 0 から 200 ポイントまで変えられます。
- **非表示のレイヤーを表示**（⇧⌘H）は、非表示または透明なレイヤーも専用のスタイルで描画します。**枠線**は、レイヤーの輪郭を単色で、またはリストのアイコンと同じ色で種類別に描き、アプリ独自のクラスだけに絞ることもできます。**枠線を表示**（⇧⌘B）で枠線のオンとオフを切り替えます。**制約の相手側を表示**（⇧⌘K）は、選択したビューの制約のもう一方の端すべてに印を付けます。これらもプレビューの下にあります。
- **計測**: レイヤーを選択した状態で、⌥ を押しながら別のレイヤーを指します。2 つのレイヤーの間の距離が、ポイント単位の値とともに 2D でも 3D でも描画されます。
- レイヤーをクリックすると選択され、リストと属性が追従します。ポインタの下のレイヤーはハイライトされます。選択したレイヤーの横のタグには、その名前とサイズが表示されます。

### 属性

右側のインスペクタには、選択したレイヤーとそのビューが表示されます。レイヤー名の下には直近の祖先が並んでツリーを上へたどれ、**親レイヤーを選択**（⌘↑）と**最初の子レイヤーを選択**（⌘↓）でその上を移動できます。続いて属性が、用途別の 5 つのセクション（コンテンツ、外観、レイアウト、動作、オブジェクト）に分かれて表示されます。フレーム、枠線、影、角丸のように、ひとまとまりの属性は 1 行を共有します。Cutaway 自身は属性の一覧を持っていません。表示されるのは [CutawayServer](https://github.com/nothingsh/CutawayServer) が送ってきたものなので、アプリに組み込まれたバージョンのサーバーが知っているものがそのまま表示されます。

- リストの上のフィールドで、属性をタイトルか ID で**フィルタ**します。セクションは折りたためます。スクロール中もいちばん上のセクションの見出しは表示されたままで、見出しを ⌥ クリックするとすべてのセクションを折りたたむか展開します。
- アプリが編集可能と示した属性にはコントロールがあります: テキストフィールド、数値フィールド、チェックボックス、16 進値と不透明度を備えたカラーフィールド、列挙型のポップアップまたはセグメンテッドコントロール、そして点、サイズ、矩形、インセット、変換の成分ごとのフィールドです。長さにはポイント単位が示されます。不透明度のような比率はパーセントで表示・入力し、不透明度にはスライダもあります。
- 変更は確定した時点で送られ、不透明度のスライダをドラッグしている間やカラーピッカーを使っている間は連続して送られます。アプリが受け付ける範囲外の値は送られず、フィールドにその理由が表示されます。アプリはレイヤーの属性で応答するため、別の属性に連動して変わる属性（ビューの alpha に連動するレイヤーの opacity など）も更新されます。
- ⌘Z で直前の変更を取り消し、⇧⌘Z でやり直せます。検査が続いている間はいつでも有効です。
- アプリが拒否した変更はその行に理由が表示され、以前の値に戻ります。

変更の後、Cutaway は影響を受けた可能性のあるレイヤーのスクリーンショットを更新します。

### 制約

レイアウトセクションには、ビューの Auto Layout 制約がアプリの報告どおりに並びます。`self.leading = Safe Area of UIView.leading + 16` のような形で、優先度が 1000 未満ならその優先度、識別子があればその識別子も表示されます。有効でない制約は薄く表示され、印が付きます。UIKit が生成した制約は 1 行にまとめられます。制約のもう一方の端をクリックすると、そのビューが選択されます。制約を指すと、そのもう一方の端にプレビューで印が付きます。**制約の相手側を表示**（⇧⌘K）は、もう一方の端すべてに一度に印を付けます。

### 更新

Cutaway に表示されるのは、問い合わせた時点でのアプリの姿です。**更新**（⌘R）はツリー全体とすべてのスクリーンショットをもう一度要求します。選択、展開の状態、カメラはそのまま保たれます。**選択したサブツリーを更新**（⇧⌘R、行のコンテキストメニューにもあります）は、そのレイヤーのサブツリーだけを要求します。アプリがバックグラウンドに移ると Cutaway は待機します。接続が切れた場合は最後の画面がそのまま残り、同じアプリが再び見つかると Cutaway は再接続します。

### アーカイブ

**アーカイブを保存…**（⌘S）は、ツリー、アイコン、そして非表示のものも含めたすべてのレイヤーのスクリーンショット、属性、制約を、ウィンドウの表示状態とともに 1 つの `.cutaway` ファイルにまとめます。このファイルは **開く…**（⌘O）、Finder から、または Cutaway のアイコンにドロップして開くことができ、専用のウィンドウで、編集以外はオンラインのときと同じように使えます。複数のアーカイブを、ライブの検査と並べて同時に開けます。

**レイヤーのスクリーンショットを書き出す…**（⇧⌘E）と**サブレイヤーを含むスクリーンショットを書き出す…**（⌥⇧⌘E）は、選択したレイヤーの画像を、デバイスのスケールで、透明度を保ち、レイヤー自身の変換と不透明度を除いて PNG として書き出します。

### 設定

**設定…**（⌘,）には 2 つのページがあります。**一般**では言語（システムの言語か、5 つのうちの 1 つ）と外観モード（システムのデフォルト、ライト、ダーク）を選びます。**プレビュー**では新しい検査の開始時の表示を選びます: 2D か 3D か、レイヤー間隔、非表示のレイヤーを表示するかどうか、枠線のスタイル、そして制約のもう一方の端すべてに印を付けるかどうかです。すでに開いているウィンドウの表示はそのまま保たれます。

## パフォーマンス

大きなインターフェースでも、即座に反応するように感じられるべきです。Cutaway はそれを中心に設計されており、テストスイートが実行のたびに下の数値を守らせます。計測は、アプリの形をした生成済みの 10,000 レイヤーのツリー（ウィンドウ、コンテナ、ナビゲーションバー、そしてアイコン、ラベル、区切り線を持つセルの長いリスト）に対して、Debug ビルドで行います。

| 操作 | 上限 |
|---|---|
| ツリーの到着 → リストが画面に表示される | 2 s |
| シーンのレイアウト | 1 s |
| カメラ移動後の新しいフレーム | 16 ms |
| 1 フレームの描画 | 16 ms |
| 行の選択 → プレビューとインスペクタが追従する | 100 ms |
| リストの検索 | 200 ms |
| すべて展開 / すべて折りたたむ | 1 s |
| ツリーのアーカイブを開く → リストが画面に表示される | 2 s |

どのように実現しているか:

- **スクリーンショットは圧縮したままです。** モデルが保持するのは、受信した圧縮済みのバイト列だけです。メインスレッドの外で展開して GPU にアップロードし、ピクセルは手放します。
- **プレビューは変化したときだけ描画します。** 何も動いていない間はフレームを送出しません。
- **読み取りは描画と歩調を合わせます。** スクリーンショットが使われるより速く届く場合、Cutaway は接続からの読み取りを止め、TCP がアプリに待つよう伝えます。メモリには何も積み上がりません。
- **何も蓄積しません。** テストスイートは 5,000 レイヤーに対してすべての操作を 10 回繰り返し、スクリーンショット、テクスチャ、リクエスト、ウィンドウが残っていないことを確認します。より長い耐久実行（`scripts/soak.sh`）は、100 ラウンドにわたるメモリの推移を出力します。
- **不正なデータでクラッシュしません。** すべてのフレームはデコードの前に検証され、パーサーは実行のたびに、変異・切り詰め・継ぎ合わせを加えたフレームでファジングされます。

## Mac 上での動作

- Cutaway は 2 秒ごとに、[CutawayServer](https://github.com/nothingsh/CutawayServer) がシミュレータで待ち受ける `127.0.0.1` のポート 48160 から 48167 と、USB で接続した各デバイスの同じポートを、システムの `usbmuxd` を通じて試します。ハンドシェイクに応答したアプリがリストに載ります。
- 接続はアプリごとに 1 つで、アプリがリストにある間は維持されます。すでにクライアントが接続しているアプリには触れません。
- 10 秒間 1 バイトも届かないリクエストは打ち切られます。[プロトコル](https://github.com/nothingsh/CutawayProtocol)が禁じるものをアプリが送ってきた場合、接続は閉じられます。
- Cutaway はそれ以外のネットワーク接続を行いません。例外は **アップデートを確認…** を選んだときで、GitHub にこのリポジトリのリリース一覧を問い合わせます。Mac についての情報は何も送りません。
- 環境設定は `UserDefaults` に、最近使ったアーカイブはシステムの最近使った書類のリストにあります。

## ロードマップ

1.0 以降に予定している方向性で、[CutawayServer](https://github.com/nothingsh/CutawayServer) と共通です。順序と範囲は変わる可能性があります。

- **インタラクションの分析。** ジェスチャーレコグナイザーと target–action の組を表示し、ジェスチャーを有効化・無効化し、オブジェクトのメソッドを呼び出します。
- **ホストアプリ向けの拡張 API。** カスタム属性、仮想の子ノード、そしてデフォルトで折りたたむクラス、色のエイリアス、画像から除外するビューなどの設定。
- **大規模な階層。** 可視レイヤーだけをキャプチャする高速モード。非常に大きな画像の分割転送。
- **より多くの接続方法とプラットフォーム。** 認証と暗号化を備えた Wi-Fi 接続。tvOS と visionOS。
- **SwiftUI。** レイヤーツリーと並べて、SwiftUI ビューの意味的な階層を表示します。

## FAQ

**アプリがリストに表示されません。**
ビルドに [CutawayServer](https://github.com/nothingsh/CutawayServer) が含まれていて（Debug ビルドにのみコンパイルされます）`CutawayServer.start()` を呼び出していること、アプリが前面にあること、デバイスの場合はケーブルで接続され、この Mac を信頼していることを確認してください。サーバーは 48160 から 48167 のうち最初に空いているポートを使います。Cutaway が話せないプロトコルバージョンのアプリも、両方のバージョンとともにリストに表示されます。

**Cutaway にネットワークは必要ですか？**
いいえ。シミュレータとはループバックアドレスで、デバイスとは USB で通信します。独自のサーバーに接続することはありません。

**ブラー、動画、Metal のビューが空白になるのはなぜですか？**
そのコンテンツはアプリのプロセスの外にあるシステムのレンダーサーバーで合成されるため、[CutawayServer](https://github.com/nothingsh/CutawayServer) はレイヤーツリーからレンダリングできません。

**デバイスなしでアプリを見ることはできますか？**
デバイスを接続している間にアーカイブを保存し、どこででも開いてください。開発用には、テストサポートライブラリがアーカイブをシミュレータ内のアプリのように再生することもできます（`scripts/replay.sh`）。

**調べることでアプリは変わりますか？**
変わるのは、自分で行った編集だけです。キャプチャは触れたものをすべて元に戻し、属性の読み取りではレイアウトは発生しません。[CutawayServer](https://github.com/nothingsh/CutawayServer) の README を参照してください。

## 開発

Cutaway は Swift 6 で、AppKit と Metal を使って書かれています。コードはローカルの Swift パッケージ `CutawayKit` にあり、アプリのターゲットはそれを組み立てるだけです。

| ターゲット | 内容 |
|---|---|
| `CutawayWire` | フレーム、値型として表したプロトコルのメッセージ、アーカイブ形式 |
| `CutawayTransport` | アプリの検出、`usbmuxd`、セッションとリクエスト |
| `CutawayModel` | レイヤーツリー、スクリーンショットと属性、ウィンドウ間で共有する状態 |
| `CutawayScene` | 各レイヤーをどこにどの順序で描くか、およびヒットテスト。純粋な Swift |
| `CutawayRender` | Metal によるシーンの描画 |
| `CutawayUI` | ウィンドウ、リスト、プレビュー、インスペクタ、設定 |
| `CutawayTestSupport` | プロトコルのフィクスチャを再生するモックサーバー、合成ツリー、偽の `usbmuxd` |

ワイヤ形式は [CutawayProtocol](https://github.com/nothingsh/CutawayProtocol) で定義され、サブモジュールとして `Protocol/` にチェックアウトされています。その Swift コードはスキーマから生成され、リポジトリにコミットされています。[CutawayServer](https://github.com/nothingsh/CutawayServer) と共有しているのはプロトコルだけです。

クローンした後、`./setup.sh` を 1 回実行してください。プロトコルのサブモジュールをチェックアウトし、Xcode、XcodeGen、jq の有無を確認し、バージョンを固定したツールを `.tools/` にインストールし、git フックを設定し、`project.yml` から `Cutaway.xcodeproj` を生成します。再度実行しても害はありません。

| 作業 | コマンド |
|---|---|
| CI と同じ手順でビルドとテストを実行（コードのみに依存） | `scripts/check.sh` |
| パッケージだけをテスト | `cd CutawayKit && DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer xcodebuild test -scheme CutawayKit-Package -destination 'platform=macOS' -testLanguage en` |
| フォーマットしてから lint | `scripts/format.sh` |
| 実行中の Cutaway に向けて、アーカイブをシミュレータ内のアプリとして提供 | `scripts/replay.sh <file.cutaway>` |
| すべての操作を 100 ラウンド繰り返し、メモリの推移を出力 | `scripts/soak.sh` |

- 目視で判断するものはありません。シーン層はユニットテストで、描画層はオフスクリーンでレンダリングして `Baselines/` の基準画像と比較します。
- テストにデバイスは不要です。接続は、この Mac 上でプロトコルのフィクスチャを再生するモックサーバーに対してテストします。
